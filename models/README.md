# Модель детекции облачков

В папке должен лежать файл весов YOLOv8:

    models/comic-speech-bubble-detector.pt

Файл не коммитится в репозиторий (см. `.gitignore`).

## Где взять

Скачайте веса с Hugging Face:

    https://huggingface.co/ogkalu/comic-speech-bubble-detector-yolov8m

Модель обучена примерно на 8k страниц манги, вебтунов, маньхуа и западных
комиксов; имя файла совпадает с тем, что ожидает код.

Альтернатива: обучить собственную модель на датасете облачков
(Roboflow Universe, Hugging Face) и экспортировать в формат YOLOv8 PT.

## Если файла нет

Приложение запустится, но детекция облачков будет отключена:
оверлей не покажет перевод, в консоли будет предупреждение детектора.
